# Changelog

## 0.1.0 - 2026-08-05

- Initial Sublime Text plugin scaffold.
- Local package-state analyzer for manifests, locks, materialization, generated
  consumer identities, and interrupted transactions.
- Correct-CLI detection to distinguish zed-pkg from the Zed editor launcher.
- Output panel, status bar, command palette, and confirmation-gated actions.
- Versioned proposal for a shared `zed inspect --format json` protocol.
- Python 3.8-compatible core tests and GitHub Actions CI.
